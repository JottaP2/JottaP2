## Sobre mim

Sou de Igreja Nova (AL), técnico em Química pelo IFAL e estudante de **Sistemas de Informação na Universidade Federal de Alagoas (UFAL)**.
Desenvolvo aplicações web com foco em **resolver problemas reais da minha região**: transporte intermunicipal, acervo da universidade, suporte de T.I. para o poder público.

- Desenvolvimento web full-stack com **Next.js, React e TypeScript**
- Projetos de pesquisa e iniciação tecnológica envolvendo **dados e visão computacional**
- Colaboração com o **LIT (Laboratório de Inovação e Tecnologia)** em sistemas para a Prefeitura de Penedo
